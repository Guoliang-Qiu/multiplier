First understand the candidate's pre-compression structure. Identify the column lists used before carry-save compression, distinguish movable partial-product signals from constants and already-compressed sum/carry signals, and choose only a small coherent region. Pay particular attention to low columns, where rounding can make small arithmetic deviations acceptable. Do not assume that three signals in one column must remain three signals: a valid transformation may delete some signals, retain one signal, move a retained signal to another column, or replace several signals with a smaller set of output slots.

For the selected region, determine a compact Boolean interface by tracing a bounded amount of upstream logic. Keep this interface small enough for practical truth-table reasoning. The interface bits are partition labels for complete input samples, not numeric multiplier operands. Use the original selected logic and any downstream compression that becomes removable as the baseline for judging whether a replacement can save cost. Keep the fixed replacement interface small: use approximately three or four output slots, and do not attempt a wider local output mapping.

Decide one concrete replacement layout before evaluating it. The layout should state which selected signals remain, which are removed, and the bit column occupied by each remaining output slot. The layout is fixed for all samples. The unresolved part is the Boolean value produced for each fixed slot as a function of the bounded local interface. Preserve the candidate's original downstream CSA/CPA behavior wherever possible, and implement the experiment in a recoverable temporary candidate rather than damaging the verified parent.

Use the available environment tools when they are useful, but choose them adaptively rather than invoking every tool by default. A dependency-analysis tool can expose the bounded local interface. A distribution-analysis tool can measure, for every local interface pattern and every Boolean output combination for the fixed slots, the complete-circuit rounded squared error. A constrained Boolean-synthesis tool can then search for a shared low-cost mapping from the local interface to the fixed-slot outputs. Do not confuse output combinations with alternative layouts: the layout has already been fixed by the experiment.

The error analysis must use complete-circuit samples. For each local interface partition and fixed-slot output combination, evaluate all samples in that partition after rebuilding the relevant compression path, quantize only the computed result, and sum squared rounded errors. Treat these sums as error energy. Combine partition energies before converting to EVM; do not add or average per-partition dB values. The final metric must agree with the normal evaluator's `20*log10(norm(error)/norm(reference))` definition.

When a synthesis result is available, integrate it only if its interface and slot ordering are understood. Remove superseded logic only when it is no longer reachable, preserve shared consumers, and ensure the resulting source still builds a valid static DAG. A distribution estimate or local gate saving is not acceptance evidence by itself: compile the candidate, validate it, run the unchanged full evaluator, and measure output-reachable weighted gate cost.
